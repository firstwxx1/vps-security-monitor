# 🛡️ VPS 多节点安全巡检与监控终端系统 (Telegram 交互机器人版)

1:1 复刻黑客攻击拦截告警（智能识别轮换代理池）与每日安全巡检日报。  
**现已支持直接在 Telegram 机器人聊天框内一键添加与纳管多台远程 VPS！**

---

## 🌟 核心特性

- **🤖 在 Telegram 机器人内直接添加与管理 VPS 节点（全新特性）**：
  - **模式 A（免手动操作）**：在 Telegram 聊天窗口中直接向机器人发送远程 VPS 的 SSH 账号密码（例如：`107.172.83.41 22 root password 美西高防`），机器人将自动通过 SSH 登录目标 VPS 并自动完成安全引擎部署与定时守护配置！
  - **模式 B（一键专属命令）**：点击机器人菜单的 `⚡ 生成专属安装命令`，复制并在任意 Linux VPS 终端粘贴，该节点会自动接入当前监控中心并向机器人发送上线握手报文！
  - **多节点统一管理**：支持在 Telegram 中随时查看所有纳管 VPS 列表 (`/nodes`)、一键对全节点或单机执行突发安全巡检 (`/check`)、生成全节点安全日报 (`/daily`)。
  - **报警与日报节点区分**：来自不同 VPS 的告警自动标注节点名称与 IP（例如：`🔔 后台登录尝试拦截 · [美西高防 (107.172.83.41)]`）。
- **🚫 Linux 内核级异常 IP 自动永久封禁与阻断引擎（全新）**：
  - **直接在内核层丢弃（DROP）**：利用独立链 `VPS-BLOCK`，一旦外部 IP 登录失败（SSH/Web）**超过 5 次**，自动下发内核级丢弃规则，零 CPU 与网络连接损耗。
  - **默认永久封禁**：封禁时效永不过期，重启自动重载恢复，黑客 IP 一经查明即彻底封死，直至管理员手动解封。
  - **静默阻断不刷屏**：封禁过程在后台静默完成，不向 Telegram 发送繁杂的单条卡片；每日安全日报自动将当天攻击次数最多（Top 5）的恶意 IP 与拦截数据汇总展示。
  - **防误封白名单安全保护**：自动豁免本机、局域网、所有已纳管 VPS 节点及当前 SSH 活跃连接客户端，杜绝误封管理员。
  - **Telegram 全功能封禁管控**：支持 `/banned` 分页查看当前黑名单、`/ban <IP>` 手动封禁、`/unban <IP>` 一键解封。
- **🖥️ 交互式终端控制面板 (`menu.sh` / `vps-guard`)**：
  - 纯终端彩色可视化配置，随时输入 `vps-guard` 即可管理 Telegram、路径防护、SSL 域名与机器人守护进程。
- **🔔 突发攻击即时拦截告警 (`check` 模式)**：
  - 增量读取 Nginx 访问日志，秒级响应，针对后台路径（如 `/api/v1/auth/login` 等）进行爆破识别。
  - **智能识别轮换代理池**：若攻击者使用几十个海外机房 IP 各尝试 1 次爆破，脚本自动命中特征并标记：`💡 每个 IP 只试 1 次，属轮换代理池，逐个封禁意义不大。`
  - 汇总恶意 User-Agent（如 `Python/3.11 aiohttp`）与攻击者组织/运营商信息。
- **🛡️ 每日安全日报 (`daily` 模式)**：
  - 统计过去 24 小时内的 Web 路径探测、后台登录撞库、SSH 密码暴力破解。
  - 统计 Fail2ban 封禁情况（包括当天新封禁与历史封禁）。
  - **陌生 IP 登录审计**：自动审计 SSH 成功登录（`Accepted password/publickey`），若不在白名单立即告警。
  - 自动检测 SSL 证书最近到期天数、系统磁盘用量、可用内存、备份校验状态。

## 🚀 一键在线部署

在你的主 VPS 上执行以下单行命令（全发行版通用，无需前置 sudo）：

```bash
curl -fsSL https://raw.githubusercontent.com/firstwxx1/vps-security-monitor/main/install.sh | bash
```

安装完成后，在终端输入：
```bash
vps-guard
```
在控制台中配置你的 Telegram `Bot Token` 与 `Chat ID`，并选择选项 **`6`** 启动 Telegram 机器人后台守护进程！

---

## 📱 在 Telegram 机器人中的使用方法

启动守护进程后，打开你的 Telegram 机器人：

### 1. 唤出控制中心
向机器人发送 `/start` 或 `/menu`，即可看到全功能的交互式控制面板：
```text
🛡️ VPS 安全巡检与监控中心
━━━━━━━━━━━━━━━━━━
📦 当前纳管 VPS: 3 台
🤖 机器人状态: 🟢 运行中
🕒 当前时间: 2026-10-22 22:00:00

[➕ 在 TG 中添加 VPS 节点]   [📋 查看 VPS 节点列表]
[🔍 立即全节点突发巡检]   [📊 获取全节点安全日报]
[⚡ 生成一键安装接入命令] [🔄 刷新控制面板]
```

### 2. 添加远程 VPS 节点（在 TG 中直接发）
点击 **`➕ 在 TG 中添加 VPS 节点`** 或直接在输入框发送：
```text
107.172.83.41 你的密码
```
或带端口与别名的完整格式：
```text
107.172.83.41 22 root 你的密码 美西CN2节点
```
机器人会自动进行 SSH 连通测试，并在 20 秒内在目标 VPS 上完成自动化部署与 Crontab 注册！

## 📋 快捷命令支持

| 命令 | 说明 |
| :--- | :--- |
| `/start` 或 `/menu` | 调出 Telegram 交互式控制主面板 |
| `/banned` | 查看防火墙当前生效的永久封禁恶意 IP 黑名单列表 |
| `/ban <IP>` | 手动将恶意 IP 加入全网内核防火墙阻断黑名单（默认永久封禁） |
| `/unban <IP>` | 立即从所有 VPS 节点防火墙中解封指定 IP |
| `/nodes` | 查看当前所有纳管的 VPS 节点及在线状态 |
| `/add` | 获取添加 VPS 的引导与一键安装命令 |
| `/check` | 立即对所有纳管的 VPS 执行突发安全检测 |
| `/daily` | 立即汇总并生成所有 VPS 的今日安全日报（含 Top 攻击源展示） |
